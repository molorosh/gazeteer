# gazeteer
a small angular website with nested pages, with some novel navigation affordances!

## Basic Setup

Angular v22 is slightly ahead of some of my other projects so I'll need to install v22 locally.

```
npm install @angular/cli@22 --save-dev
```

also added a basic .gitignore in the root folder.

```
node_modules/
dist/
.vs/
```

## Web App Setup

Now to create the webapp with the local ng v22

```
npx ng new ngapp
```
Using the following options:
- Which Stylesheet system: Sass (SCSS)
- SSR and SSG: No
- AI Tools: VSCode
